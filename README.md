# FrankenTillería

Juego 2D de artillería por turnos para 2 jugadores. Ensambla tu criatura en el laboratorio de Víctor y destruye a tu rival.

Proyecto final de Programación Asistida por IA. Equipo: Edgar (núcleo), Mike (laboratorio), Debanhi (combate).

## Requisitos
Node 22.13 o superior (`node -v`). Con nvm: `nvm install 22`.

## Correr el proyecto
```bash
npm install
npm run dev       # servidor local
npm test          # pruebas unitarias
npm run lint      # estilo y buenas prácticas
npm run build     # versión para Vercel
npm run balance   # reporte de balance de las partes
```
